# dm-forge releases

Installers for **dm-forge**, a desktop DM console that turns a D&D 5e adventure PDF into a playable map-and-rooms console. This repo holds release files only.

Download the newest release from [Releases](https://github.com/nlewis84/dm-forge-releases/releases/latest):

- **Mac:** `dm-forge-<version>-mac.dmg` (Apple Silicon and Intel). Drag dm-forge to Applications, then right-click it and choose **Open** the first time. If macOS says the app is damaged, run `xattr -cr /Applications/dm-forge.app` once.
- **Windows:** `dm-forge-<version>-win-x64.exe`. On the SmartScreen warning, click **More info**, then **Run anyway**.

After that, dm-forge updates itself: an **Update** button appears in the app when a new version is out.

The builds aren't signed by Apple or Microsoft, which is why the first launch needs the extra step.
